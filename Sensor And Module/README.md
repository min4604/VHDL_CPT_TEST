# Sensor And Module — 感測器與模組

本資料夾收錄常見感測器與周邊模組的 VHDL 驅動與應用範例。除特別註明外，系統時脈皆為 **50MHz**、重置為 **低態 (`'0'` 重置)**。

| 項目 | 介面 | 說明 |
|------|------|------|
| [DHT11](./DHT11) | 單線 (1-wire) | 溫濕度感測器驅動與週期讀取頂層 |
| [`KEY4_4.vhd`](./KEY4_4.vhd) | GPIO 矩陣 | 4x4 矩陣鍵盤掃描 + 除彈跳 |
| [LED8X8_R_G](./LED8X8_R_G) | GPIO 掃描 | 8x8 LED 點矩陣掃描與捲動動畫 |
| [SD178B](./SD178B) | I2C | SD178BM 語音播放模組 (播放 microSD 內的 wav) |
| [ST7735_TFTLCD](./ST7735_TFTLCD) | SPI | ST7735 128x160 彩色 TFT LCD 初始化與填色 |
| [TSL2561](./TSL2561) | I2C | 數位光照度感測器，計算 Lux 值 |
| [UART](./UART) | UART | 8N1 串列收發器，鮑率 300 ~ 38400 可選 |

## KEY4_4.vhd — 4x4 矩陣鍵盤

| 埠 | 方向 | 說明 |
|----|------|------|
| `clk`, `reset` | in | 50MHz 時脈、低態重置 |
| `COL[3:0]` | out | 行掃描 (一次拉低一行) |
| `ROW[3:0]` | in | 列輸入 (需上拉，按下為 `'0'`) |
| `bt_dt_out[3:0]` | out | 按鍵編號 0 ~ 15 (即掃描碼) |
| `vail` | out | 有效按鍵，除彈跳後輸出一個低態脈波 |
| `fre` | out | `'1'` 表示按鍵已放開 |

運作方式：`scan_code` 不斷遞增輪流掃描 16 個鍵；某鍵按下時掃描停住，連續 5 次讀到按下才輸出 `vail`，連續 5 次讀到放開才設 `fre='1'`，避免按鍵彈跳造成重複觸發。

---

> 共用的 I2C 驅動 (`i2c2wdriver2.vhd`、`sd178BMI2C2wdriver.vhd`) 介面相同：
> 上層設定好位址/資料後把 `RESET` 由 `'0'` 拉到 `'1'` 啟動，等 `I2Cok='1'` 表示完成 (`I2CS='1'` 為失敗)；
> 連續讀寫時每完成 1 byte 會送出 `D_W_R_Nok`，上層回 `reWR` 後再繼續。
