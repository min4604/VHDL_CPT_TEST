# SD178B — 語音播放模組 (I2C)

SD178BM 為 I2C 介面的語音模組，可播放 microSD 卡中的 wav 檔，也可直接播放文字語音。
I2C 位址為 `0x20` (`0100000`)。

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `SD178B.vhd` | 頂層：以「語音命令表」依序送出命令，依 MO0 狀態自動播放下一個 wav 檔 |
| `sd178BMI2C2wdriver.vhd` | SD178BM 專用 I2C 主控端驅動 (含喚醒序列、連續寫入、失敗重試) |

## SD178B.vhd 介面

| 埠 | 方向 | 說明 |
|----|------|------|
| `clk50M`, `reset_in` | in | 50MHz 時脈、低態重置 |
| `SD178BMI2C_SCL` | out | I2C SCL |
| `SD178BMI2C_SDA` | inout | I2C SDA (需上拉電阻) |
| `SD178BMI2Co_reset` | buffer | 模組硬體 reset |
| `SD178BMI2Ci_MO0` | in | 模組 MO0 狀態腳 (用來判斷播放結束) |
| `number_in` | in | 保留 (目前未使用) |

## 運作方式

1. `SD178BMI2C_sound` 為命令表，`(0)` 為長度，其後為要送出的位元組。
2. `SD178BMI2C_P` 自動逐筆送出並處理各指令需要的等待時間 (立即指令、reset、等待播放結束等)。
3. 每次 MO0 上升緣 (一段播放結束) `mp3` 加 1，依序播放 `1001.wav`、`1002.wav`…

## 常用指令 (詳見 `SD178B.vhd` 檔頭)

| 指令 | 說明 |
|------|------|
| `80` | 停止並清除 buffer (V2.2 版會轉為硬體 reset) |
| `81` / `82` | 音量 +0.5dB / -0.5dB |
| `83 xx` | 播放速度加快 xx% |
| `86 xx` | 設定音量 (`FF`~`00`，預設 `D2`) |
| `87 xxxxxxxx` | 延遲 xx ms |
| `88 hhhh nnnn` | 播放 `hhhh`(十進位 1001~9999).wav，重複 `nnnn` 次 (0 = 無限) |
| `8A xx` | 設定 MO2~MO0 輸出腳 |
| `8B xx` | 設定 WM8960 輸出聲道 (喇叭 / 耳機 / Line out) |
| `8F 00~03` | 暫停 / 繼續 / 跳過 / 軟體重開機 (V2.2) |
