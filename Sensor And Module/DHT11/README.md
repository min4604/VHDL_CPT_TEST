# DHT11 — 溫濕度感測器

DHT11 使用單一資料腳 (單線雙向) 傳輸 40 bit 資料：

```
濕度整數(8) + 濕度小數(8) + 溫度整數(8) + 溫度小數(8) + 檢查碼(8)
```

檢查碼 = 前 4 個 byte 相加的低 8 位。資料手冊請見 `DHT11_datasheet-En.pdf` / `DHT11_datasheet-chinese.pdf`。

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `DHT11_driver.vhd` | DHT11 通訊驅動 (YHGL 版)。送出起始信號、接收 40 bit、比對檢查碼、失敗自動重試 |
| `DHT11_out.vhd` | 頂層：產生 driver 所需時脈，週期性 (約每 2 秒) 讀取並鎖存溫濕度 |

## DHT11_driver 介面

| 埠 | 方向 | 說明 |
|----|------|------|
| `DHT11_CLK` | in | 操作時脈 781.25kHz (50MHz / 64，週期 1.28us) |
| `DHT11_RESET` | in | `'0'` 重置；拉到 `'1'` 開始讀取 |
| `DHT11_D_io` | inout | DHT11 資料腳 (需上拉電阻) |
| `DHT11_tryN` | in | 失敗後重試次數 |
| `DHT11_ok` | buffer | `'1'` 表示作業完成 |
| `DHT11_S` | buffer | `'1'` 表示讀取失敗 |
| `DHT11_RDp` / `DHT11_DBo` | in / out | 依指標讀出第 0~4 byte (5 = 計算出的檢查碼) |
| `DHT11_DBoH`, `DHT11_DBoT` | buffer | 濕度、溫度整數值 |
| `DHT11_DBoH1/0`, `DHT11_DBoT1/0` | out | 濕度、溫度的十位 / 個位 (可直接接七段顯示) |

## 通訊流程 (driver 狀態機 `ss`)

1. `"00"`：FPGA 拉低資料線約 21ms 作為起始信號，再釋放
2. `"01"`：等待 DHT11 拉低；高態超過約 49us 判定為 `'1'`，否則為 `'0'`
3. `"10"`：等待 DHT11 拉高；收滿 40 bit 後比對檢查碼
4. `"11"`：錯誤處理，依 `DHT11_tryN` 延遲約 1.4 秒後重試

## DHT11_out 介面

| 埠 | 方向 | 說明 |
|----|------|------|
| `clk`, `reset` | in | 50MHz 時脈、低態重置 |
| `DHT11_D_io` | inout | DHT11 資料腳 |
| `DHT_OK` | out | `'1'` 表示已有有效資料 |
| `BoT_int`, `BoH_int` | out | 溫度、濕度 (整數) |
| `BoT`, `BoH` | out | 溫度、濕度 (8 位元) |
