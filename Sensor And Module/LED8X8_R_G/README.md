# LED8X8_R_G — 8x8 LED 點矩陣

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `LED8X8.vhd` | 8x8 點矩陣行掃描顯示，並以「每行循環右移」產生水平捲動動畫 |

## 介面

| 埠 | 方向 | 說明 |
|----|------|------|
| `clk`, `reset` | in | 50MHz 時脈、低態重置 (重置時載入預設圖形) |
| `r` | in | `'1'` 暫停捲動 |
| `pwm_in` | in | 掃描致能，`'1'` 時掃描前進 (可接 PWM 做亮度/閃爍控制) |
| `COL[7:0]` | out | 行選擇 (one-hot) |
| `ROW[7:0]` | out | 列資料 |

## 時脈

- 行掃描：`div(16)` ≒ 763Hz，8 行輪流點亮 → 整體更新率約 95Hz
- 動畫：`div(23)` ≒ 6Hz

## 已知問題

- 內部信號 `ROW_d` 已算出目前行的圖形，但**沒有指定給輸出埠 `ROW`**，
  實際使用時需在架構中加上 `ROW <= ROW_d;` (或依模組極性加上 `not`) 才會顯示。
- `r='1'` 時原本的「上下捲動」程式碼已被註解，目前只會暫停。
