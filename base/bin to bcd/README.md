# bin to bcd — 二進位轉 BCD

本資料夾以不同方法實作「二進位 → BCD (Binary Coded Decimal)」轉換，方便比較演算法與硬體寫法。

## 檔案說明

| 檔案 | 方法 | 說明 |
|------|------|------|
| `bintobcd.vhd` | 移位加三法 (Double Dabble) | 10 位元輸入 (內部固定為 589) → 16 位元 BCD，每個時脈處理 1 位元 |
| `bin8toseg7.vhd` | 移位加三法 + 七段掃描 | 8 位元輸入 → BCD，並以 4 位數七段顯示器掃描顯示，`busy` 表示轉換中 |
| `bintobcd_sub.vhd` | 連續減法法 | 8 位元輸入 → 3 位數 BCD，依序減 200/100/50/10，`start` 啟動、`busy` 表示轉換中 |

## 移位加三法 (Double Dabble)

每處理一個輸入位元 (由 MSB 至 LSB)：

1. 檢查每個 BCD 位數 (4 bit)，若 **大於 4 則加 3**
2. 整個 BCD 暫存器 **左移 1 位**，並移入下一個輸入位元

n 位元輸入重複 n 次即可得到結果。

## 連續減法法

每個時脈嘗試由大到小減去 200 / 100 / 50 / 10，並把對應的值加到百位或十位，
剩下不足 10 的部分即為個位數。電路簡單，但所需時脈數隨輸入值變動。
