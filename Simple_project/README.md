# Simple_project — 簡易專案

本資料夾收錄結合多個基礎元件的小型 VHDL 專案，適合在學會基本語法後練習「頂層 + 元件例化」的設計方式。

| 檔案 / 資料夾 | 說明 |
|---------------|------|
| `Clock.vhd` | MM:SS 計時器，4 顆七段顯示器顯示 (需搭配 [`seg7/oneseg7/seg7.vhd`](../seg7/oneseg7/seg7.vhd)) |
| [PUF](./PUF) | 環形振盪器 PUF (物理不可複製函數)，以振盪頻率差異產生晶片指紋位元 |

## Clock.vhd

- 輸入：`ck_50M` (50MHz)
- 輸出：`Hex1`~`Hex4` = 秒個位 / 秒十位 / 分個位 / 分十位
- 以 `DF(25)` (約 1.49Hz) 作為計時時脈，初始值為 34:56，59:59 後回到 00:00。
- 若需要精準 1 秒，可改用 `divider_n` (N = 50,000,000) 產生 1Hz。
